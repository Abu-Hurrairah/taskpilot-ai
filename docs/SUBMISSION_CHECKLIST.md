# Final 10–15 minute checklist (after first local setup)

## Minutes 0–3: app and API
- Start backend; open /health and /docs.
- Run Flutter on Android with your config.json. Use USB adb reverse if networking fails. The bundled preview/web is an immediate browser fallback while Android setup completes.
- Generate the mixed demo goal, inspect all categories and save the plan.
- Complete/uncomplete a task; refresh/restart and confirm persistence.

## Minutes 3–6: RevenueCat
- Configure free Test Store key, current offering and taskpilot_pro product attachment.
- Restart app with compile-time defines, verify Test Store label and catalog prices.
- Test success, cancel and restore. Confirm entitlement and dashboard evidence.
- If not configured, state that limitation honestly; a preview is not billing proof.

## Minutes 6–9: media
- Capture Home, generated plan, Tasks progress, Today and Pro; include onboarding if available.
- Record the 2–3 minute script in DEMO_SCRIPT.md. Use one take.

## Minutes 9–12: submission
- Create/push your public repository (no .env, config.json, database, user data or secrets).
- Add your actual test results, video URL and screenshots.
- Paste DEVPOST.md and adjust only claims you can demonstrate.
- Check organizer dates, eligibility, required RevenueCat evidence, video length and source accessibility. Verify that the submission window is actually open; this package does not certify event eligibility.

## Minutes 12–15: final check
- Run flutter analyze and flutter test locally if not already done.
- Verify the repository link opens publicly and the video plays.
- Submit using your account; nothing in this project automatically publishes or submits.

If Flutter/Android SDK is not installed yet, first-time SDK setup/build can exceed 15 minutes. Finish that before this checklist.
